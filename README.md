# Jasa IPB — aplikasi HP

Kerangka aplikasi (PWA) untuk Dashboard Jasa IPB. Tidak berisi data maupun kunci: semua data dibaca langsung dari
Google Sheet pemilik lewat Apps Script, dan kunci hanya tersimpan di HP yang dipasangi.

- `index.html` — aplikasi pemilik (Dashboard, Jadwal, Harian, Bulanan, Pasien, Pengaturan, Scan, Bagikan)
- `teman.html` — halaman jadwal untuk teman (hanya jadwal; lewat tautan bagikan yang bisa dicabut)
